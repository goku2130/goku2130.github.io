## Hello, World!

Welcome to my portfolio and blog. I'm excited to finally have a place to share my projects, thoughts, and things I'm learning as a developer.

## About This Site

This portfolio is built with a modern tech stack:

- **Next.js 15** — React framework with server-side rendering and the App Router
- **Tailwind CSS** — Utility-first styling for a clean, responsive design
- **MDX** — Markdown with JSX support for rich blog content
- **Contentlayer** — Type-safe content management from Markdown files

The site features dark mode support, full-text search, syntax highlighting, and is optimized for performance.

## What to Expect

I plan to write about:

- **Web development** — Tips, tutorials, and deep dives into frontend and backend topics
- **Project walkthroughs** — Behind-the-scenes looks at things I'm building
- **Learning in public** — Sharing what I learn as I explore new technologies
